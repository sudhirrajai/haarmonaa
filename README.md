# Haarmonaa Luxury E-Commerce Platform

Haarmonaa is a modern, full-stack luxury jewelry and accessories e-commerce web application built with **Laravel 12, Inertia.js v3, React 19, TypeScript, and Tailwind CSS**.

## Features
- **Storefront & Design**:
  - Full-bleed 50/50 Split Hero Slider with dynamic CMS controls
  - Dynamic Seasonal & Curated Collection showcases
  - Best Selling curated 4x2 grid
  - Interactive Featured Products horizontal carousel
  - Shop by Category and Gram full-width galleries
  - Real-time Global Cart, Mini-Cart Drawer, and Wishlist
  - Dynamic Checkout with Razorpay & Cash on Delivery (COD)
- **Admin Management Studio**:
  - Products & Variations Matrix builder
  - Collections Management with multi-product picker
  - Homepage CMS Studio for Hero Slider, Seasonal drops, and Promo Banners
  - Orders, Customer, and Category managers

## Tech Stack
- **Backend**: Laravel 12, PHP 8.3+, SQLite / MySQL
- **Frontend**: React 19, Inertia.js v3, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
